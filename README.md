# Sistema Hospitalar em C

## Sobre o projeto

Simulação de um sistema hospitalar desenvolvida para a disciplina de
Algoritmos e Estruturas de Dados.

O sistema utiliza diferentes estruturas de dados para organizar pacientes,
atendimentos e registros.

## Estruturas implementadas

- Pilha
- Fila
- -Lista
- Heap
- Árvore AVL

## Funcionalidades

- Cadastro de pacientes
- Organização da fila de atendimento
- Priorização de casos
- Busca de registros
- Armazenamento de dados em arquivos

## Tecnologias utilizadas

- Linguagem C
- Manipulação de arquivos
- Estruturas de dados

## Como executar

```bash
gcc *.c -o hospital
./hospital
